# Surviving mutants that cannot change any result, by rule. One rule per line:
#     function glob | regex on the changed lines | class | reason
# The changed lines are the "-old" and "+new" lines of `mutmut show`; the regex is searched in them. tools/audit/mutation.py
# reports every survivor no rule matches as UNCLASSIFIED. Classes: "equivalent" (no input changes any output),
# "equivalent in range" (no input the task can produce changes any output; the condition is stated),
# "performance" (same result, other speed), "text" (a printed number rounds to the same digits).

# ---- gate.py
mrgym.gate.gap_lower_bound | \+.*np\.asarray\((ref|abl), (None)?\) | equivalent | the other operand is converted to float, so the difference is the same float array
mrgym.gate.gap_lower_bound | \+.*sd = .* if (\(n > 1\) or True|n >= 1) else 0\.0 | equivalent | sd is read only when n > 1 (the return statement tests n again)
mrgym.gate.gap_lower_bound | \+.*if n > 1 else 1\.0$ | equivalent | sd is read only when n > 1
mrgym.gate.decide | \+.*\{101 \* (BLIND_MAX|SEP_MIN):\.0f\} | text | the reason prints the threshold without decimals: 10.1 and 25.25 print as 10 and 25
mrgym.gate.run | \+.*pool\.map\(_play, .*(chunksize=(None|2)\)|\], \))$ | performance | the chunk size of the process pool changes scheduling only
mrgym.gate._instance | \+.*task_id_for\(spec, seed_hex, \), split\) | equivalent in range | the gate builds instances of public splits only (gate, tune), where the trainer-side label does not depend on the split
mrgym.gate._tune | \+.*_instance\(spec, level, f"\{k\}:\{i\}", \) | equivalent | "tune" is the default split of _instance
mrgym.gate.load | \+.*open\(_path\(env_id\), (encoding=(None|"UTF-8"))?\) | equivalent | the stored result is ASCII JSON
mrgym.gate.write | \+.*open\(path, "w", (encoding=(None|"UTF-8"))?\) | equivalent | json.dump writes ASCII
